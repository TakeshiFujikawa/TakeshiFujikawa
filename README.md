# VitaOne（仮称）

WHOOP・ヘルスプラネット・ASICS Runkeeper の3アプリを「ひとつ」に融合し、
さらに大胆に削ぎ落として誰でも迷わず使える健康管理アプリの設計ドキュメント＆モックアップです。

複数アプリを行き来して数値を見比べる手間をなくし、
**「今日、自分は何をすればいいか」が一目でわかること**を最優先にしています。
