# 2. 画面構成・主要機能

タブは5つに固定し、迷わせない。各画面は「結論を最初に・詳細はその下」の縦構成で統一する。

```
[ホーム] [記録] [走る] [食事] [トレンド]
```

## 2-1. ホーム（ダッシュボード）— WHOOPの「リカバリー」を翻訳

**役割**：今日のコンディションスコアと「今日やること」を一目で見せる。

- 最上部：コンディションスコア（0〜100）＋ ひとことコメント
  - 例）82「絶好調。今日は強度高めの運動もOK」
  - 例）45「回復が追いついていません。今日は軽めに」
- スコアの内訳（タップで展開）
  - 💤 回復：睡眠時間・睡眠の質・安静時心拍（WHOOP由来の指標を簡略翻訳）
  - 🏃 活動：直近の運動負荷・継続日数（Runkeeper由来）
  - 🍽 栄養：直近の食事バランス・カロリー収支（ヘルスプラネット由来 + 写真解析）
- 「今日のおすすめアクション」カード（1枚だけ）
  - 運動提案（例：軽いジョグ20分 / 完全休養）
  - 食事提案（[3章 献立提案機能](03-meal-suggestion-spec.md) への導線）

**スコア算出の考え方**（詳細はアルゴリズム実装時に調整）：

```
コンディションスコア = 回復スコア(40%) + 活動バランス(30%) + 栄養バランス(30%)

回復スコア   ≈ 睡眠時間・睡眠効率・安静時心拍の変動から算出（WHOOPのリカバリー相当を簡略化）
活動バランス ≈ 直近7日の運動負荷と回復のバランス（オーバートレーニングを検知）
栄養バランス ≈ 直近の食事ログのPFCバランス・カロリー収支
```

## 2-2. 記録 — ヘルスプラネットの体組成記録を簡略化

**役割**：体重・体組成・睡眠などの「身体データ」を、入力の手間なく可視化する。

- スマート体組成計／ウェアラブルとのBluetooth連携（自動同期が前提、手入力は補助）
- 表示するのは「体重」「体脂肪率」「直近の変化（▲0.3kg / 1週間）」のみに絞る
- 詳細グラフ（体重推移・睡眠の推移）はこの画面の下部にまとめて格納
- 目標設定は1つだけ。複数目標を持たせて混乱させない
  - 例（本アプリの想定利用シナリオ「2026年5月30日からの健康管理プログラム」）：
    **「1年で -15kg、同時に筋力アップ」**（2026/5/30 〜 2027/5/30・期間進捗を%表示）
  - 「減量」と「筋力アップ」を同時に狙う目標のため、体重だけでなく
    体脂肪率・筋肉量（連携機器が対応していれば）の推移も併せて表示し、
    「体重は減っているが筋肉量も保てているか」を確認できるようにする

## 2-3. 走る — Runkeeperのラン記録を簡略化

**役割**：GPSでの運動記録を、ワンタップで開始・終了できるようにする。

- 大きな「スタート」ボタン1つ（種目選択：ラン／ウォーク／その他は自動判定で代替）
- 記録中は「経過時間・距離・ペース」の3つだけを大きく表示（地図は終了後に表示）
- 終了後のサマリー画面で「消費カロリー」を算出し、ホームの活動スコア・
  食事提案（運動量に応じたカロリー調整）に自動連携する
- ルート履歴・実績バッジはRunkeeper同様に保持するが、メイン導線には出さない
  （「もっと見る」から確認する位置づけ）

## 2-4. 食事 — ヘルスプラネットの食事記録 + 写真からの献立提案（本アプリの目玉機能）

**役割**：食事を「記録」するだけでなく「次に何を食べるか」を提案する。

- メイン導線は **カメラボタン1つ**：食事の写真を撮るだけで記録が完了
  - 写真から料理名・推定カロリー・PFC（タンパク質/脂質/炭水化物）をAIが自動推定
  - ユーザーは推定結果を確認し、必要なら品目を修正するだけ（手入力はゼロを目指す）
- 記録後、その場で「次の食事はこうするのがおすすめ」という献立提案を表示
  - 詳細仕様は [3章：写真からの献立提案機能](03-meal-suggestion-spec.md) を参照
- 1日のカロリー収支・PFCバランスをシンプルなバー表示で確認できる

## 2-5. トレンド — 3アプリの「グラフ地獄」を1枚のレポートに統合

**役割**：週次・月次の振り返りを、複数グラフではなく「1枚のサマリーカード」で見せる。

- 週次レポート（自動生成）
  - コンディションスコアの推移（折れ線1本）
  - 「今週よかったこと」「来週に向けて」をテキストで2〜3行要約
  - 体重・運動量・睡眠の主要指標を数値カードで併記（グラフは折りたたみ表示）
- 月次では同様のフォーマットで、目標（2-2の体重目標など）の進捗を可視化

## 2-6. 設定（タブには出さず、ホーム右上から遷移）

- 連携デバイス管理（体組成計・ウェアラブル・GPS）
- プロフィール（年齢・性別・身長・活動量・**アレルギー/食事制限**・健康目標）
  - ここで設定したアレルギー・目標が、献立提案のすべての判定に使われる
- 通知設定（記録忘れ防止・週次レポート通知）
