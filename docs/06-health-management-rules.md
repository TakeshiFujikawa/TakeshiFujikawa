# 6. 健康管理ルール（確定仕様・2026年6月12日版）

> 2026年6月12日時点でユーザー本人から共有された、日々の健康管理プログラムの
> **完全な運用ルール**。[3. 写真からの献立提案機能](03-meal-suggestion-spec.md)で定義した
> 各条件（条件1〜条件7）を、より具体的な日次運用フロー・フォーマットとして
> 確定したものであり、本ドキュメントの内容が最新の運用ルールとなる。
>
> 体組成の基準値は本書 [6-11](#6-11-体組成目標最新基準値) の値（2026年6月12日時点）を
> 最新の基準とし、[03-meal-suggestion-spec.md](03-meal-suggestion-spec.md) 3-0-1節の
> 数値（5月14日時点）はベースライン比較用の過去データとして保持する。

## 6-1. 1日の基本スケジュール

| 時間 | 内容 |
|---|---|
| 起床後すぐ | 朝のルーティン開始 |
| ルーティン終了後 | 全献立自動提案（朝・昼・夕・間食） |
| 昼食終了後 | 夕食献立を自動提案 |
| 毎食後 | 次の食事時間を提案 |
| 20:00 | 夕食終了・鉄則（[6-9](#6-9-20時ルール鉄則)） |
| 23:59 | 1日の最終まとめ（[6-13](#6-13-2359-最終まとめ内容)） |

## 6-2. 朝のルーティン（毎日記録）

| 順番 | 内容 | カロリー | たんぱく質 |
|---|---|---|---|
| 1 | ⚖️ Health Planet体組成測定 | — | — |
| 2 | 🥤 水 300ml | 0 kcal | 0g |
| 3 | 🫗 純梅肉エキス | 10 kcal | 0g |
| 4 | 💪 VALXプロテイン 1杯 | 76 kcal | 16.2g |
| 5 | 🌿 DR.CLEANZ青汁 1袋 | 20 kcal | 1g |
| 6 | 🫘 黒豆茶 1L（随時） | 10 kcal | 0g |

- 報告があった分のみ記録する。
- 朝のルーティン終了後 → 自動で全献立（朝・昼・夕・間食）を提案する。
- 各項目のカロリー・たんぱく質は1日の摂取量計算に含める。

## 6-3. 献立提案ルール

### フォーマット（毎回固定）

毎朝・昼・夕食 **各9選**

| カテゴリ | 件数 |
|---|---|
| 🥘 自炊 | 5選 |
| 🛵 GoFood | 2選 |
| 🍱 日本食レストラン | 2選 |
| 🍪 間食 | 5選 |

> プロトタイプ（`lumi_app_prototype.html`）では、画面サイズとデモ時間の都合上、
> 上記9選のうち代表的な5案（主に🥘自炊・🛵GoFood）を表示している。
> 本実装ではカテゴリタブ等で全9選＋間食5選を表示する想定（[5. ロードマップ](05-roadmap.md)参照）。

### 提案内容

- 毎日、前日と被らないメニューにする。
- 調理法・食材をローテーションする。
- カロリー・たんぱく質を毎回明記する（[条件7](03-meal-suggestion-spec.md#条件7食べる順番摂取順序の提案)に合わせ、品目総量(g)も明記）。
- 各メニューに「内臓脂肪・体脂肪への効果」を明記する。


## 6-4. 除外・制限メニュー

| 種類 | 内容 |
|---|---|
| 🚫 永久除外 | 豆乳鍋・刺身 |
| 🚫 週2回まで | 麺類・揚げ物 |
| 🚫 飲み物除外 | ココナッツウォーター |

> 補足：[03-meal-suggestion-spec.md](03-meal-suggestion-spec.md) 3-4節の朝ルーティンに
> 記載されていた「ココナッツウォーター」は、本書を最新ルールとして**飲み物除外**に変更する。
> また「刺身」を新たに永久除外に追加する。

## 6-5. 優先メニュー

- 🥇 鍋全般（豆乳以外）
- 🥇 焼き魚全般
- 🥇 和食全般

## 6-6. 化学調味料ルール

- アミノ酸等（MSG）→ できるだけ使わない。
- 市販品チェック時 → 添加物を毎回明記する。
- レシピ提案時 → 無添加を優先する。

## 6-7. 食事記録ルール

### 毎食の記録内容

- 時刻
- 食品名・量
- カロリー・たんぱく質・脂質・糖質
- 原材料チェック（市販品のみ）
- 食べる順番の提案（[6-8](#6-8-食べる順番毎回提案)）
- 噛む回数（1口30回）
- 内臓脂肪・体脂肪への効果コメント

### 市販品チェック

- 原材料を必ず確認する。
- 化学調味料を明記する。
- 健康への影響を評価する。

## 6-8. 食べる順番（毎回提案）

1. 🥤 水・黒豆茶（食前）
2. 🥗 野菜・海藻・きのこ
3. 🥩 魚・肉・卵・豆腐
4. 🍲 味噌汁・スープ
5. 🍚 ごはん（最後・少なめ）

**1口30回・20分以上かけて食べる。**

> 補足：[03-meal-suggestion-spec.md](03-meal-suggestion-spec.md) 条件7の「①野菜・汁物 →
> ②たんぱく質 → ③主食」の3ステップを、本書では「食前の水分 → 野菜系 → たんぱく質 →
> 汁物 → 主食」の**5ステップ**に細分化し、咀嚼回数・食事時間の目安も加える。
> 毎食の提案・記録には必ずこの5ステップ＋咀嚼/時間の目安をセットで添える。

## 6-9. 20時ルール（鉄則）

| ルール | 内容 |
|---|---|
| 夕食終了 | 20:00までに必ず終了 |
| 20時以降 | 水・黒豆茶のみOK |
| 例外 | VALXプロテインのみOK |
| 夜食 | 完全禁止 |

## 6-10. 水分目標

- 毎日2,500ml以上（ジャカルタの気温を考慮）
- 黒豆茶1L＋水1,500ml
- 食前に必ずコップ1杯

## 6-11. 体組成目標（最新基準値）

| 項目 | 現在（6/12） | 次の目標 |
|---|---|---|
| 体重 | 89.20kg | 86.00kg |
| 体脂肪率 | 30.20% | 27.00% |
| 内臓脂肪 | 15.5 | 13.0 |
| 基礎代謝 | 1,765 kcal | 1,800 kcal |
| 体内年齢 | 51才 | 47才 |

## 6-12. 「今」と言われたら

「今」と問われた場合は、**必ず現在時刻を確認してから回答する**
（食事提案・ルーティンの判定はすべて現在時刻基準のため）。

## 6-13. 23:59 最終まとめ内容

1. 本日の全記録（時刻・食事・水分）
2. 目標値との比較（[6-11](#6-11-体組成目標最新基準値)・1日の目標値：カロリー1,800〜1,900kcal／
   たんぱく質80〜90g／脂質50〜60g／糖質180〜220g／水分2,500ml以上）
3. 食事傾向分析
4. 体組成への影響予測
5. 体組成推移表
6. 翌日の全献立提案（[6-3](#6-3-献立提案ルール)のフォーマットで朝・昼・夕・間食）
